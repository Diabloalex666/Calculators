# Стоп-лист FinPulse

Никогда:

- Залп из десятков статей на молодом домене.
- Выдуманные ставки, лимиты СФР, МРОТ, пороги НДФЛ.
- Кириллица и заглавные буквы в URL.
- Вторая статья на тот же интент (смотри `seo-agent/semantic-map.json`).
- Статья, которая отбирает запрос у денежной страницы-калькулятора: в тексте — ссылка на калькулятор, не конкурирующий title.
- Перелинковка на другие свои домены.
- Покупные ссылки и накрутка поведения.
- Пустой сдвиг `dateModified` без правки смысла.
- Публикация без гейта `python scripts/quality-gate.py`.
- Секреты (токены Вебмастера, GSC, Telegram) в репозитории.
