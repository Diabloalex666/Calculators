# Один раз: подключить Яндекс к заводу

Цель: ты кладёшь токены, дальше завод сам тянет спрос каждый день. Логин/пароль Яндекса в репозиторий и в чат не пишем.

## 1. Вебмастер API (обязательно для авто-спроса)

1. Открой [oauth.yandex.ru](https://oauth.yandex.ru/) → зарегистрируй приложение (тип «для доступа к API»).
2. Права: **Яндекс.Вебмастер** (чтение статистики / hostinfo).
3. Получи OAuth-токен для своего аккаунта (тот же, где подтверждён finraz.ru).
4. В GitHub: репо `Diabloalex666/Calculators` → **Settings → Secrets and variables → Actions → New repository secret**:
   - `YANDEX_WEBMASTER_TOKEN` = токен
   - `YANDEX_WEBMASTER_HOST_ID` = необязательно. Если сайт один — завод найдёт `finraz.ru` сам. Иначе ID вида `https:finraz.ru:443`
5. Локально (по желанию): файл `F:\AI\side-income\.env` (уже в `.gitignore`):

```
YANDEX_WEBMASTER_TOKEN=сюда_токен
```

Проверка:

```powershell
cd F:\AI\side-income
python scripts/yandex_api.py
```

Ожидание: `"webmaster": {"connected": true, ...}`. Ошибку 403/404 чини по тексту в `seo-agent/raw/webmaster-live.json`.

## 2. Wordstat (опционально)

У Яндекса **нет бесплатного публичного Wordstat API** для произвольных аккаунтов. Частотность «сколько ищут в РФ» завод берёт так:

| Способ | Что нужно | Статус |
|--------|-----------|--------|
| Вебмастер popular queries | токен выше | уже в заводе — показы/клики **твоего** сайта |
| Подсказки Яндекса | ничего | уже в заводе — живой язык запросов |
| XMLRiver Wordstat | платный аккаунт | опционально: Secrets `XMLRIVER_USER` + `XMLRIVER_KEY` |
| CSV вручную | выгрузка Wordstat | `seo-agent/raw/wordstat*.csv` |

Без XMLRiver завод **не выдумывает** частотности. Ранг тем = живые показы Вебмастера + подсказки.

## 3. Что крутится само после токена

Каждый день (и на пуш):

1. Тянет ТОП запросов Вебмастера по finraz.ru  
2. Обновляет семена подсказок под изменившийся спрос (`seo-agent/raw/seeds.json`)  
3. Пишет новые planned-темы (кап 2/сутки), без дублей калькулятора  
4. Собирает HTML только при verified-факте  
5. Публикует не больше 1 статьи/сутки + IndexNow  
6. Темы без фактуры старше 45 дней → `retired`

Твоё влияние после шага 1: иногда подкинуть verified-цифру в `facts.json` (НДФЛ/лимиты СФР), если тема новая и закона в базе ещё нет.
