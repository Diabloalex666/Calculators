# Выгрузки для цеха консолей

Положи CSV в эту папку. Завод на следующем прогоне сам соберёт `console-summary.json` и обновит панель.

Секреты и JSON-ключи сюда не класть.

## Google Search Console

1. GSC → Эффективность → Экспорт → CSV.
2. Имя файла лучше с `gsc` (например `gsc-queries.csv`).
3. Нужные колонки: Query, Clicks, Impressions, Position (английские заголовки экспорта подходят).

## Яндекс.Вебмастер

1. Вебмастер → Поисковые запросы → выгрузка.
2. Имя с `webmaster` или `yandex`.
3. Подхватываются колонки «Запрос», «Клики», «Показы», «Позиция».

## Метрика

1. Метрика → отчёт по визитам → экспорт CSV.
2. Имя с `metrika`.
3. Колонка «Визиты» / Visits.

Без файлов цех не падает: панель пишет «файлов нет». API-ключи кабинетов в репозиторий не коммитим.
