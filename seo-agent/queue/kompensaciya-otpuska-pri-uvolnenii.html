Компенсация отпуска при увольнении

Неиспользованные дни отпуска при увольнении не «сгорают»: за них платят денежную компенсацию.

Алексей В., редактор калькуляторов FinPulse · Обновлено: 2026-09-29

Неиспользованные дни отпуска при увольнении не «сгорают»: за них платят денежную компенсацию. Норма: ст. 127 ТК РФ — при увольнении выплачивается денежная компенсация за все неиспользованные отпуска.

Формула / рамка

Компенсация = средний дневной заработок × неиспользованные дни отпуска

Как считать по шагам

  1. Считают неиспользованные дни по правилам отпуска (ст. 127 ТК РФ).
  2. Средний заработок — по правилам среднего (в т.ч. коэффициент 29,3 для полного месяца).
  3. Сумму вместе с остальным расчётом выдают в день увольнения (ст. 140 ТК РФ).

Свою цифру на руки или по среднему проверьте в калькулятор отпускных — без регистрации.

Частые вопросы

Можно ли вместо денег догулять отпуск?

По соглашению с работодателем можно предоставить отпуск с последующим увольнением. Иначе — компенсация деньгами.

Это то же, что отпускные?

Близко по среднему заработку, но основание — увольнение и ст. 127 ТК РФ, не уход в отпуск.

Источники
